# polelo

There is no widely accepted **direct one-word translation** of **STEM (Science, Technology, Engineering and Mathematics)** in Sepedi (Sesotho sa Leboa), because it is an English acronym. Instead, it is usually translated descriptively.

Some good options are:

1. **Saense, Theknolotši, Boentšeneare le Dipalo**

   * Science = **Saense**
   * Technology = **Theknolotši**
   * Engineering = **Boentšeneare** (or **Boentšhinere**, depending on terminology used)
   * Mathematics = **Dipalo**

2. **Dithuto tša Saense, Theknolotši, Boentšeneare le Dipalo**

   * Literally: "Studies of Science, Technology, Engineering and Mathematics."

3. If you want to keep the international acronym:

   * **STEM (Saense, Theknolotši, Boentšeneare le Dipalo)**

For educational materials in South Africa, the third option is often the clearest because learners and teachers are already familiar with the acronym **STEM**, while the Sepedi expansion explains its meaning.

A concise Sepedi rendering is:

> **STEM = Saense, Theknolotši, Boentšeneare le Dipalo**
